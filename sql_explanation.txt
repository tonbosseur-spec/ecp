Voici la requête SQL pour ajouter la colonne `sessions` (de type JSON) à votre table `course_modules` :

```sql
ALTER TABLE course_modules 
ADD COLUMN IF NOT EXISTS sessions JSONB DEFAULT '[]'::jsonb;
```

**💡 Note importante :** 
Vous **n'avez pas besoin** d'exécuter cette requête pour que l'application fonctionne !

Si vous préférez séparer proprement les données et utiliser cette nouvelle colonne `sessions` dans la base de données, n'hésitez pas à me le dire, j'adapterai le code en conséquence !
